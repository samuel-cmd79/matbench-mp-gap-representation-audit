# Legacy diagnostic baseline notebooks

These notebooks are retained only to document the archived pre-freeze runs.
They are not the formal training pipelines used for the frozen benchmark
scores.

- `mp_gap_baseline_v1.ipynb`: pre-freeze Level-1 baseline.
- `mp_gap_baseline_v2.ipynb`: older Level-2 imputation policy; its raw
  predictions are diagnostic only.

The formal frozen Level-1 and Level-2 training records are the notebooks in
`../../notebooks/`.  Python exports of these baseline notebooks are
intentionally omitted to avoid two apparent canonical entry points.
